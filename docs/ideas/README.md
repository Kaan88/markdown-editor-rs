# The apps that may join mdedit, mdview and Hub

The long list, with a verdict on each, is `docs/ecosystem-ideas.md`. This folder holds the plans
written for the ones the owner asked about. Nothing here is a decision to build; each plan ends
with the questions it is waiting on. The drawings are branches of this repository, each with its
pictures in `shots/mock-*/` and a README there; they are never merged.

| Idea | Plan | Drawing (branch) | Where it stands |
|---|---|---|---|
| Hub, a launcher and updater | `launcher-plan.md` | `mock/launcher` | **Built** as its own app, `Kaan88/mdhub` (`Desktop\hub`); its own `docs/STATE.md` is the record. mdedit and mdview give it a version resource and `hub.txt` (D-098) |
| A terminal, Windows first | `terminal.md` (why it is possible), `terminal-plan.md` (the plan) | `mock/terminal` | Planned; waits for the owner |
| A file manager, standard layout, split view | `file-manager-plan.md`, `file-manager-mockup.md`, `file-manager-context-menu.md`, `file-manager-questions.md`; the commander layout and plugin support in `commander-plugins.md` | `mock/file-manager` | Planned; the context menu is option B, the other questions open |
| A task manager | `task-manager-plan.md` | `mock/task-manager` | Planned; waits for the owner |
| A downloader | `ecosystem-ideas.md` 6b to 6d | `mock/downloader` | Drawn and costed; waits for the owner |
| A local-LLM workbench, as a tab of mdedit | `ecosystem-ideas.md` 8 | `mock/workbench` | Drawn; waits for the owner |
