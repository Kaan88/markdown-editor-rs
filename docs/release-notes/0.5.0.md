Command palette, settings, compare, replace in files, live preview in mdview, and a Linux version.

mdedit 0.5.0 is the first release for Linux and the first since 0.4.0. Version 0.4.1 was never
published, so this release also holds its changes.

## What is new

Commands and settings

- A command palette (fuzzy search over every command, with "Go to line").
- A Settings dialog, including "Make mdedit the default" on Linux and the update controls.
- Every menu item has an icon, and checked items have their own check-mark column.
- Menus taller than the window scroll and stay below the title row; a submenu opens beside its parent.
- A window shadow (KDE's own on KDE, a drawn one on other Wayland desktops, none on X11).

Files and panes

- Compare two files, and replace in files across a folder.
- The same file can be open in both panes of the split.
- Find remembers its earlier searches, and replace can be limited to the selection.

Editing

- Macros can be saved under a name and played again.
- Code folds by mouse, with a chevron in the gutter.
- Auto-pairing, and indentation that follows the file: tabs or spaces are detected per file (status
  strip field "Spaces: 4" or "Tabs", and a setting to turn it off).
- Line commands (sort, reverse, remove duplicates, join, move) and Markdown commands (bold,
  italic, code, strikethrough, heading level, align table).

With mdview

- "Preview in mdview" opens the file in the viewer at the caret's line, and the viewer shows the
  unsaved text as you type (live preview). If the editor closes, the viewer returns to the saved file.

Linux

- The same editor on Linux, with native file dialogs, the window's own icon in the panel, colour
  emoji, and an update check.

## Downloads

Windows

- `mdedit-setup-0.5.0.exe`: the installer. Per user, adds mdedit to "Open with" and takes no default. Updates itself.
- `mdedit-0.5.0-windows-x86_64.exe`: the bare executable, no installation. Updates itself.
- `mdedit-0.5.0-windows-x86_64.zip`: the same executable with LICENSE and README.md, as a portable folder. Updates itself if the folder is writable.

Linux (x86-64)

- `mdedit-0.5.0-linux-x86_64.AppImage`: runs on any distribution; make it executable and run it. Updates itself.
- `mdedit-0.5.0-linux-x86_64.tar.gz`: `install.sh [PREFIX]` (default `~/.local`) and `uninstall.sh`. Does not update itself.
- `mdedit_0.5.0_amd64.deb`: Debian 11+, Ubuntu 20.04+ and derivatives. Does not update itself.
- `mdedit-0.5.0-1.x86_64.rpm`: Fedora, openSUSE, RHEL and derivatives. Does not update itself.
- `PKGBUILD`: Arch. Put it in a folder and run `makepkg -si`; it installs the tar.gz as `mdedit-bin`. Does not update itself.

`mdedit-update.txt` is the update manifest the app reads; it is not for download.

The deb, rpm, tar.gz and Arch installs install a desktop file, so the taskbar icon and "Open with"
work without the AppImage's first-run registration. The AppImage writes its own desktop entry and
icon on first run and registers its file types without taking a default.

Linux needs glibc 2.31 or later (the builds are made in an Ubuntu 20.04 container), and the
system's fontconfig, freetype and X11/xcb libraries. libcurl and the Wayland libraries are loaded
at run time if present.

## Known limits

- The Windows files are not code-signed, so SmartScreen may warn.
- Windows was checked by automated tests and screenshots on a Windows runner (the full test suite
  and every screenshot state, built natively), not by hand. The installer wizard clicked through
  by a person, taskbar and Explorer icons, SmartScreen with unsigned files and interactive use on a
  Windows desktop have not been checked.
- Linux was run on KDE Plasma 6 (Wayland) and on sway. GNOME, other desktops, X11, fractional
  scales in a real window and monitors with different scales have not been tried.
- x86-64 only: no ARM builds. The deb and rpm are not signed.
