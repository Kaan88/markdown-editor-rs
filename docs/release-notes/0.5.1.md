Fixes submenus that closed before the pointer could reach them.

## Fixed

- A submenu (View, Macro, Open recent, and Lines, Convert and Markdown in the right-click menu)
  closed as soon as the pointer left its item, so nothing in it could be chosen with the mouse.
  It now stays open while the pointer travels to it. Another item of the parent menu closes it
  only after the pointer has rested there for a moment.
