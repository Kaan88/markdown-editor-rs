mdedit 1.2.0: edit Markdown on the rendered page, choose a file's language, several custom AI providers with or without a key, and fixes from the second audit.

## New

- **Edit on the page.** With the preview pane open on a Markdown tab, Ctrl+E (or **Edit on the page** in the tab menu and the command palette) gives the whole text area to the rendered page. Click a block to edit its source in a box at its place on the page; Esc, a click outside the box, or moving the caret out of the block closes it. Undo, find and every other command work as they do in the text. Ctrl+E again goes back to the text.
- **Language of a file.** Click the language in the status bar to choose another one. The choice is kept for that file; nothing is written into the file.
- **A text file the AI turns into Markdown** switches to Markdown at once, and a bar offers to rename it to `.md`. Undo takes back the switch and the bar.
- **Custom AI providers:** add as many as you like in **AI: Settings**, each with its own name, base URL, model and effort. The API key is optional, so local servers and services that need none work, also where no credential store runs.
- **Modify** next to a saved prompt, in the Rewrite panel and in the AI menu, puts the prompt in the instruction box to be changed, without running it.
- **The caret and scroll position come back** when you open a file again, for the 100 files used last.
- **The days before unused tabs are offered for closing** are a setting (Settings > Session), from 1 to 365; the default is still 7.

## Fixed

- **Two windows on one session.** Opening several files at once from Explorer could start two windows that each thought the session was theirs, and closing one could drop the unsaved text the other kept. Now the first window takes the files; a second start waits for it.
- **A session file that could not be read** at start (held by another program, a disk error) was taken as empty, and the next exit could drop the unsaved text it listed. mdedit now tries again for a moment, and if it still cannot read the file, it leaves the file alone and says so.
- **Don't save, then Cancel** while closing several tabs no longer drops the first tab's recovery copy.
- After a crash during exit, unsaved text no longer comes back twice.
- An update and the repair of a missing program beside mdedit can no longer write the same files at once, and update files are on disk before they replace the old ones.
- About's OK button can be clicked while the preview pane is open.
- Renaming a file moves its recovery copy, bookmarks and find results with it, and never replaces a file that appeared under the new name meanwhile.
- A user name and password in a custom provider's address are no longer shown in error messages.
