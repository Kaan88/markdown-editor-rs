mdedit 1.1.1: AI rewriting with Claude Code, Codex, the Claude API or any OpenAI-compatible service, and sturdier recovery of unsaved text.

## New

- **AI rewriting.** Format as Markdown, Fix Markdown, Rewrite with an instruction of your own, and your saved prompts, on the selection or the whole document. The result opens in a review, where you apply it, copy it or close it; nothing changes until you apply. Choose the connection in **AI: Settings**: Claude Code or Codex installed on this computer, the Claude API, or an OpenAI-compatible service (OpenAI, OpenRouter, Groq, Together, DeepSeek, Mistral, Gemini, xAI, Ollama, LM Studio, or a base URL of your own), with the model and effort. Off until you choose a connection. API keys are kept in the system's credential store, never in mdedit's settings, and are taken out of any error message.
- While a rewrite runs, a strip moves across the top of the status bar and the status text takes the accent colour.
- **Save prompt** in the instruction box (or Ctrl+S) keeps what you typed as a saved prompt, named after its first words.
- Pasting the full path of an image (as Explorer's Copy as path gives it) into a saved Markdown document inserts a link to the image, as dropping the file does, from any folder or drive.
- The AI work runs in a separate program, `mdedit-ai`, installed beside mdedit. A copy that updates itself from 1.0.6 fetches it at its next start.

## Fixed

- **Unsaved text after a crash.** Every draft now has a lasting identity, so a recovery copy and the text kept at the last exit can no longer be mistaken for each other: when it is not certain which is which, both come back. A recovery copy that cannot be read for the moment is kept for the next start, and one whose text is damaged gives way to the text kept at the last exit.
