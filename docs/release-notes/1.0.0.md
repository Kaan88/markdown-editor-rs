mdedit 1.0: a live preview beside your Markdown, a format bar, pinned tabs and crash reports.

## New

- **Preview pane.** Press Preview in the bar (or View > "Preview in this window") to see the rendered page beside the text, drawn by mdview's own renderer. It updates as you type, and formulas and diagrams are drawn too. mdview does not need to be installed: mdedit now ships with the small engine that draws them.
- **Synced scrolling.** Scroll the text and the page follows, or scroll the page and the text follows; both reach their ends together. When you move the caret, the page brings its line into view.
- **Format bar.** A row of buttons under the bar for Markdown documents: bold, italic, strikethrough, code; headings 1 to 3 (Ctrl+1/2/3); bulleted, numbered and task lists, quotes and alerts (note, tip, important, warning, caution); links, images, tables, code blocks; math, diagrams, footnotes, collapsible sections and rules. A button shows pressed when the caret is in what it makes. Turn it off in View > "Format bar". Every command is also in the Markdown menu, with the table commands in their own Table submenu.
- **Pinned tabs.** "Pin tab" in the tab menu keeps a tab first, with a pin in place of its close button, and out of the way of "Close other tabs" and "Close all tabs". Pinned tabs come back with the session.
- **Crash reports.** If mdedit ever crashes, it writes a short report, and on the next start a bar offers to open or copy it, so it can be sent along with a bug report. A report never holds your text or file names, and nothing is sent anywhere.
- **Text being composed in an input method** (Japanese, Chinese, Korean and others) is shown where it will be typed.
- **macOS** (Apple silicon and Intel; first added to 0.7.1) now updates itself like the Windows and Linux versions, and text inserted from Emoji & Symbols or dictation is typed.
