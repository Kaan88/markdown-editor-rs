mdedit 1.0.4: the preview pane's cursor, and ticking a box no longer scrolls the page.

## Fixed

- **The cursor over the preview pane** is a hand over a task box, the text cursor over text, and the arrow elsewhere. In 1.0.3 it was the text cursor everywhere.
- **Ticking a task box on the preview pane** leaves the page where it is. In 1.0.3 the page jumped to the editor's caret, often the top of the document.
