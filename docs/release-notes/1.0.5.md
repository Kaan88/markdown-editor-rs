mdedit 1.0.5: the tab left showing comes back, pinned or not, and a setting to start on the last pinned tab.

## Fixed

- **The tab showing when the window closed** is the one that shows at the next start. A pinned note with no file came back as the tab next to it.

## New

- **Start on the last pinned tab** (Settings, under Restore tabs at start): the window opens on the pinned tab you used last instead of the tab you left showing. Off by default.
