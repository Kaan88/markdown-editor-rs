mdedit 1.0.6: an offer to close tabs you have not opened in a week, and an installer that leaves scripts alone and opens .txt files.

## New

- **Close tabs not opened in a week.** At start, a bar offers to close the tabs you have not opened in the last 7 days you used mdedit (days you do not use it are not counted). Close them, Keep (their count starts again), or close the bar to be asked at the next start. Pinned tabs, the tab showing and tabs with unsaved changes are never offered. On by default: Settings, under Session.
- **.txt files open with mdedit** when installed with the installer (the task "Open .txt files with mdedit", ticked). Where Windows already has another app chosen for .txt, the installer offers to open Default apps.

## Fixed

- **Scripts run again.** The installer no longer lists mdedit under Open with for scripts and web pages (.bat, .cmd, .ps1, .js, .py, .sh, .html and others), and takes off the entries earlier versions wrote. Run the installer once to get this: an in-app update replaces only mdedit itself.
