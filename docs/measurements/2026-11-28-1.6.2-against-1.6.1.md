# mdedit 1.6.2 against 1.6.1, after the release

Measured 2026-11-28 on the Windows PC with `tools/compare-builds.py`, 9 interleaved runs. A is the
published `mdedit-1.6.1-windows-x86_64.exe`, B the published `mdedit-1.6.2-windows-x86_64.exe`
(its SHA-256 matches `mdedit-update-2.txt`). Every start had `--no-session`, `--behind` and
`MDEDIT_SETTINGS` naming a scratch `settings.ini`.

```
sample.rs                    A         B      B-A   A range / B range
  first frame ms         66.50     66.80    +0.30   65.60-80.90 / 65.70-69.90
  idle private MiB       27.60     27.60    +0.00   27.30-27.80 / 27.20-28.10
  keystroke p50 ms        0.47      0.54    +0.07   0.46-0.51 / 0.53-0.55
  keystroke p95 ms        0.53      0.65    +0.12   0.52-0.72 / 0.60-0.69
  scroll p50 ms           0.40      0.45    +0.05   0.39-0.40 / 0.44-0.46
  scroll p95 ms           0.48      0.57    +0.09   0.46-0.48 / 0.55-0.59

sample.md                    A         B      B-A   A range / B range
  first frame ms         96.00     96.20    +0.20   95.40-98.60 / 94.90-98.50
  idle private MiB       36.60     36.40    -0.20   36.20-37.10 / 36.00-36.60
  keystroke p50 ms        0.65      0.71    +0.06   0.64-0.66 / 0.70-0.72
  keystroke p95 ms        0.71      0.82    +0.11   0.70-0.71 / 0.78-0.89
  scroll p50 ms           0.53      0.60    +0.07   0.52-0.55 / 0.59-0.61
  scroll p95 ms           0.56      0.67    +0.11   0.56-0.60 / 0.64-0.71
```

- **First frame and memory:** the same.
- **Keystroke and scroll frame:** B is 0.05 to 0.12 ms slower, about 12 %, in both files, and
  the ranges do not overlap, so it is not noise. Both stay far inside the budgets (8 ms, 4 ms).
  Not explained: neither mdedit's diff nor the toolkit's (48eedb8 to 84c0fc8: `FieldInput`, the
  pointer routes, the deprecations, `cancel`) adds work to a frame with no palette open; the
  two exes are separate CI builds, so code placement is one candidate. Split into stages
  (`sample.rs`, `--scroll-steps 300`, 7 more interleaved runs, medians of the per-run means), all
  of it is in paint:

  ```
  A 1.6.1: p50 0.390  layout 0.000  paint 0.280  compose 0.010  copy 0.110  present 0.160
  B 1.6.2: p50 0.450  layout 0.000  paint 0.340  compose 0.010  copy 0.110  present 0.140
  ```

  Neither diff changes the text painter or anything mdedit paints with no palette open.
- **`sample.md` idle memory** is over the 30 MiB budget in both builds (the preview); not new.
- Not measured: idle CPU, the 100 MB file, a frame with the palette's edit menu open (whole-window
  redraw while it is open).
