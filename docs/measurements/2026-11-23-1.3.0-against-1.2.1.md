# 1.3.0 (main) against 1.2.1, before the release

Measured 2026-11-23 on the Windows PC with `tools/compare-builds.py`, 7 interleaved runs, every
window `--behind`, a scratch settings file (`MDEDIT_SETTINGS`), `--no-session`. A is the tag
`v1.2.1` (`528446a`) with only `--behind` (`0e4a2d5`) applied so its windows stayed behind; B is
`main` at `db377b2` (the Hub merge and the two shorter Settings labels came after and touch
nothing at start).

**Verdict.** No change. `sample.md` is over the first-frame and memory budgets in 1.2.1 already,
by the same amount; 1.3.0 adds nothing on the launch path.
