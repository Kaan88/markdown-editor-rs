
## macOS

`APP-VERSION-macos-aarch64.zip` is for Apple Silicon Macs, `APP-VERSION-macos-x86_64.zip` for
Intel Macs; macOS 12 or later. Unzip it and move `APP.app` to Applications. The app is not
signed by a registered developer, so the first time, right-click it and choose Open (or run
`xattr -dr com.apple.quarantine APP.app`).
